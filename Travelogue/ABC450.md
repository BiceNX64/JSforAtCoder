## 🔠 [ABC450-C](https://atcoder.jp/contests/abc450/tasks/abc450_c)

```javascript
// ABC450
// https://atcoder.jp/contests/abc450/tasks/abc450_c
// 2026-04-05

'use strict';
const fs = require('fs');

function Main(input) {
  const args = input.trim().split(/\s+/);
  let cur = 0;
  const next = () => args[cur++];
  const nextNum = () => Number(next());
  const nextBigInt = () => BigInt(next());
  // const lines = input.replace(/\r/g, '').trim().split(/\n/);

  // 👇️ ロジックを記述 👇️
  
  // 1. 初期値の取り込みや必要な配列の準備
  const H = nextNum();
  const W = nextNum();
  const grid = [];
  for (let h = 0; h < H; h++) {
    const line = next().split('');
    grid.push(line);
  }
  const visited = Array.from({ length: H }, () => new Uint8Array(W));
  const queue = [];
  
  // 2. 外周部分の白マスの探索
  for (let i = 0; i < H; i++) {
    for (let j = 0; j < W; j++) {
      if (i === 0 || i === H - 1 || j === 0 || j === W - 1) {
        if (grid[i][j] === '.' && !visited[i][j]) {
          visited[i][j] = 1;
          queue.push([i, j]);
        }
      }
    }
  }
    
　// 3. 外周に隣接する白マスの探索
  const dx = [1, -1, 0, 0];
  const dy = [0, 0, 1, -1];
  let head = 0;
  while (head < queue.length) {
    const [r, c] = queue[head++];
    for (let i = 0; i < 4; i++) {
      const nr = r + dy[i];
      const nc = c + dx[i];
      if (
        nr >= 0 &&
        nr < H &&
        nc >= 0 &&
        nc < W &&
        grid[nr][nc] === '.' &&
        !visited[nr][nc]
      ) {
        visited[nr][nc] = 1;
        queue.push([nr, nc]);
      }
    }
  }
  
  // 4. 外周と繋がらない白マスの探索
  let ans = 0;
  for (let i = 1; i < H - 1; i++) {
    for (let j = 1; j < W - 1; j++) {
      if (grid[i][j] === '.' && !visited[i][j]) {
        ans++;
        const islandQueue = [[i, j]];
        visited[i][j] = 1;
        let islandHead = 0;
        while (islandHead < islandQueue.length) {
          const [r, c] = islandQueue[islandHead++];
          for (let k = 0; k < 4; k++) {
            const nr = r + dy[k];
            const nc = c + dx[k];
            if (
              nr >= 0 &&
              nr < H &&
              nc >= 0 &&
              nc < W &&
              grid[nr][nc] === '.' &&
              !visited[nr][nc]
            ) {
              visited[nr][nc] = 1;
              islandQueue.push([nr, nc]);
            }
          }
        }
      }
    }
  }
    
  console.log(ans);

  // 👆️ ロジックを記述 👆️
}

Main(
  require('fs').readFileSync(
    process.platform === 'linux' ? '/dev/stdin' : process.argv[2],
    'utf8',
  ),
);

```

全然解けなかったので早々にGeminiに回答例を見せてもらいました。

1. 初期値の取り込みや必要な配列の準備
   1. 受け取った$H$と$W$で2次元の配列を用意
   2. `visited`と`queue`という配列を用意
   3. 探索済みを管理する`visited`の配列については`Uint8Array()`を使うことでメモリ消費を抑える

2. 外周部分の白マスの探索
   1. 4辺を調べて、白マスがあれば調べるための待ち行列`queue`に座標を登録
   2. `&& !visited[i][j]`の部分はなくても動作上は問題ない

3. 外周に隣接する白マスの探索
   1. `queue`の中の白マスの座標を1つずつ取り出していく
   2. `queue`を順番に処理する際には`head`をポインタにして進めていく
   3. 取り出した外周にある白マス座標について、W×Hの枠からはみ出さない範囲で、4方向に白マスがあるかどうかを探索
   4. もし白マスが見つかれば`queue`に追加していく
   5. `queue`の中の座標をすべてチェックするまでループ
   6. 外周に隣接する白マスの調査が完了したら、残りがカウントすべき白マスになる

4. 外周と繋がらない白マスの探索
   1. 新しく白マスが見つかったらまずカウントする
   2. 新しく見つかった白マスに対して、隣接する白マスを探索していき、見つかれば`visited`として登録していく
   3. これを繰り返して、全ての白マスをvisitしていく

コードを自分の言葉で説明してみました。コードを読めば理解はできるのですが、なかなか自分でこれを時間内に実装することはまだまだ難しいです。この問題は待ち行列を使った幅優先探索の典型的な問題だと思うので、流れを丁寧に理解し、ゼロから自力で書けるように反復しようと思います。

1. Importing initial values and preparing necessary arrays
   1. Prepare a 2D array with the received $H$ and $W$.
   2. Prepare arrays named `visited` and `queue`.
   3. For the `visited` array that manages explored cells, use `Uint8Array()` to reduce memory consumption.
2. Searching for white cells on the outer perimeter
   1. Check the four sides, and if there is a white cell, register its coordinates in the queue `queue` for investigation.
   2. The `&& !visited[i][j]` part is not strictly necessary for it to work.
3. Searching for white cells adjacent to the outer perimeter
   1. Take out the coordinates of the white cells from the `queue` one by one.
   2. When processing the `queue` in order, use `head` as a pointer to move forward.
   3. For the extracted white cell coordinates on the outer perimeter, search in four directions for white cells within the bounds of the W×H grid.
   4. If a white cell is found, add it to the `queue`.
   5. Loop until all coordinates in the `queue` are checked.
   6. Once the investigation of white cells adjacent to the outer perimeter is complete, the remaining ones are the white cells to be counted.
4. Searching for white cells not connected to the outer perimeter
   1. When a new white cell is found, count it first.
   2. For the newly found white cell, search for adjacent white cells, and if found, register them as `visited`.
   3. Repeat this to visit all white cells.
