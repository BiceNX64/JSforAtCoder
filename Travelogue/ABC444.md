## 🔠 [ABC444-C](https://atcoder.jp/contests/abc444/tasks/abc444_c)

```javascript
// ABC444
// https://atcoder.jp/contests/abc444/tasks/abc444_c
// 2026-02-07

"use strict";
const fs = require('fs');

function Main(input) {
    const args = input.trim().split(/\s+/);
    let cur = 0;
    const next = () => args[cur++];
    const nextNum = () => Number(next());
    const nextBigInt = () => BigInt(next());
    // const lines = input.replace(/\r/g, '').trim().split(/\n/);

    // 👇️ ロジックを記述 👇️

    const N = nextNum();
    const A = [];
    for (let i = 0; i < N; i++) {
        A.push(nextNum());
    }

    A.sort((a, b) => a - b);

    const answers = new Set();

    /**
     * 検証関数
     * @param {number} targetL - 検証するLの長さ
     * @param {boolean} skipTarget - Lと等しい要素を除外するか（パターンA用）
     * @returns {boolean} - Lとして成立するかどうか
     */
    const check = (targetL, skipTarget) => {
        let left = 0;
        let right = N - 1;

        if (skipTarget) {
            while (right >= 0 && A[right] === targetL) {
                right--;
            }
        }

        while (left < right) {
            if (A[left] + A[right] !== targetL) {
                return false;
            }
            left++;
            right--;
        }

        if (left === right) {
            return false;
        }

        return true;
    }

    const candidate1 = A[N - 1];
    if (check(candidate1, true)) {
        answers.add(candidate1);
    }

    const candidate2 = A[0] + A[N - 1];
    if (check(candidate2, false)) {
        answers.add(candidate2);
    }

    const result = Array.from(answers).sort((a, b) => a - b);
    console.log(result.join(" "))


    // 👆️ ロジックを記述 👆️
}

Main(require("fs").readFileSync(process.platform === 'linux' ? "/dev/stdin" : process.argv[2], "utf8"));
```

まず、配列Aについてsortします。`L`の値については、

- 1本以上折れなかった場合: `A[N-1]`
- すべて折れた場合: `A[0]+A[N-1]`

の2通りがあり、この2つのパターンについて検証が必要です。わたしはそれぞれの場合について、判定するAの要素の数や最大値となる要素の数がそれぞれ奇数または偶数の場合で場合分けしたり`for`文を使って複雑化してしまったため、テストケースは解けたものの場合分けがうまくできずに提出ではエラーとなってしまいました。

検証用関数のポイントとしては、`left`と`right`の2つのポインタをコントロールして、Lの候補を検証することです。具体的には、

- `skipTarget`が`true`、つまり`targetL`が`A[N-1]`の場合は、`A[right]`が`targetL`と一致しなくなるまで`right--`でポインタを動かす。
- `left<right`であるとき、`A[left]+A[right]`が`targetL`と一致するか検証。
  - 一致しなければ`false`を返し、一致する場合は`left++`、`right--`でそれぞれポインタを動かしていく。
- `left === right`の場合は`false`を返す。これがあるため判定する要素の数が奇数か偶数かという場合分けが不要。

この2つのポインタをコントロールする検証用関数の考え方はとても勉強になりました。

First, I sort array *A*. For the value of *L*, there are two patterns to verify:

- Case where one or more didn't break: `A[N-1]`
- Case where all broke: `A[0] + A[N-1]`

Verification of these two patterns is required. I initially over-complicated it by trying to distinguish cases based on whether the number of elements or the number of max elements were odd or even, and using complex for-loops. While I passed the basic test cases, I couldn't handle the edge cases correctly in the submission, resulting in errors.

The key point for the verification function is controlling two pointers, `left` and `right`, to validate candidate values for *L*. Specifically:

- If `skipTarget` is true (meaning `targetL` is `A[N-1]`), move the `right` pointer until `A[right]` no longer matches `targetL`.
- While `left < right`, verify if `A[left] + A[right]` matches `targetL`.
  - If they don't match, return `false`. If they do, move `left++` and `right--` respectively.
- If `left === right`, return `false`. This logic eliminates the need to separately check for odd or even counts of elements.

The concept of controlling two pointers in a verification function was a great learning experience.
