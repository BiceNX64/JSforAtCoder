## 🔠 [ABC446-C](https://atcoder.jp/contests/abc446/tasks/abc446_c)

```javascript
// ABC446
// https://atcoder.jp/contests/abc446/tasks/abc446_c
// 2026-02-26

"use strict";
const fs = require('fs');

function Main(input) {
    const args = input.trim().split(/\s+/);
    let cur = 0;
    const next = () => args[cur++];
    const nextNum = () => Number(next());
    const nextBigInt = () => BigInt(next());
    // const lines = input.replace(/\r/g, '').trim().split(/\n/);

    // 👇️ ロジックを記述 👇️

    for (let t = 0; t < T; t++) {
        const N = nextNum();
        const D = nextNum();
        const A = [];
        const B = [];
        for (let i = 0; i < N; i++) A.push(nextNum());
        for (let i = 0; i < N; i++) B.push(nextNum());

        const queue = [];
        let head = 0;
        let totalEggs = 0;

        for (let i = 0; i < N; i++) {
            queue.push({ amount: A[i], day: i });
            totalEggs += A[i];
            let needed = B[i];
            while (needed > 0) {
                if (queue[head].amount <= needed) {
                    needed -= queue[head].amount;
                    totalEggs -= queue[head].amount;
                    head++;
                } else {
                    queue[head].amount -= needed;
                    totalEggs -= needed;
                    needed = 0;
                }
            }

            while (head < queue.length && (i - queue[head].day + 1) >= D) {
                totalEggs -= queue[head].amount;
                head++;
            }
        }
        console.log(totalEggs);
    }
    // 👆️ ロジックを記述 👆️
}

```

N日間のあいだ、消費期限を持った玉子の仕入と消費と廃棄について、先入れ先出しの管理方法で在庫管理していく、という問題です。キューと呼ばれる待ち行列を使って解きます。

`T`でループを回して各ケースについてテストしていきます。必要な`N`、`D`、`A`、`B`を取得したあと、配列`queue`、変数`head`と`totalEggs`を初期化します。`head`は`queue`の中からいちばん古い在庫を指し示すマークになります。

```javascript
    for (let t = 0; t < T; t++) {
        const N = nextNum();
        const D = nextNum();
        const A = [];
        const B = [];
        for (let i = 0; i < N; i++) A.push(nextNum());
        for (let i = 0; i < N; i++) B.push(nextNum());

        const queue = [];
        let head = 0;
        let totalEggs = 0;
```

次にN日目までの在庫の動きを管理するロジックです。配列`queue`に仕入れた数`A[i]`と日付`i`をオブジェクトとして格納し、`totalEggs`に`A[i]`を加えます。さらに`needed`という変数にその日の使用量`B[i]`を初期値としてセットします。

```javascript
        for (let i = 0; i < N; i++) {
            queue.push({ amount: A[i], day: i });
            totalEggs += A[i];
            let needed = B[i];
```

ここからがコアな在庫管理のアルゴリズムになります。`needed`が初期値として`B[i]`がセットされた使用しなければいけない数(未振り分けの使用量)ですが、古い在庫から優先して振り分けていき`needed`がゼロになるまで(`while (needed > 0)`)振り分ける処理を進めます。

```javascript
            while (needed > 0) {
                if (queue[head].amount <= needed) {
                    needed -= queue[head].amount;
                    totalEggs -= queue[head].amount;
                    head++;
                } else {
                    queue[head].amount -= needed;
                    totalEggs -= needed;
                    needed = 0;
                }
            }
```

`if`の部分については、もし未振り分けの使用量`needed`が`queue`の先頭の値より大きい場合、`needed`と`totalEggs`の値を減らし、さらに`head`が次の`queue`を指し示すようにインクリメントします。`else`の場合、つまり`head`が指し示す`queue`の現在の値が未振り分けの使用量`needed`より大きい場合、その現在の値と`totalEggs`から`needed`の値を引き、さらに`needed`をゼロにします(未振り分けがなくなったため)。未振り分けがなくなったら`while`のループから抜け出して次の処理に移ります。

2つ目の`while`は賞味期限の判定です。`(i - queue[head].day + 1) >= D`のように、現在の日付からいちばん古い在庫の日付が賞味期限以内に収まるまで、`totalEggs`から賞味期限の在庫の数を減らして処分しつつ`queue`の位置を示す`head`をインクリメントする処理を繰り返します。`head < queue.length`の条件がない場合、例えば`head` と`queue.length`の値が等しい場合、`(i - queue[head].day + 1) >= D`がエラーを起こす可能性があります。

```javascript
            while (head < queue.length && (i - queue[head].day + 1) >= D) {
                totalEggs -= queue[head].amount;
                head++;
            }
```

処理が終わったら`totalEggs`の値を出力し、次の`T`のループに移り、これを繰り返します。

This problem involves managing egg inventory—stocking, consuming, and discarding—over $N$ days using a First-In-First-Out (FIFO) method with expiration dates. It can be solved using a queue.

I iterate through each test case using the loop with `T`. After getting $N, D, A, \text{and } B$, I initialize the `queue` array, the `head` variable, and `totalEggs`. `head` acts as a marker pointing to the oldest stock in the queue.

```javascript

        const N = nextNum();
        const D = nextNum();

        const B = [];

```

Next is the logic to manage inventory movements up to day $N$. I store the stocked amount `A[i]` and the date `i` as an object in the `queue` and add `A[i]` to `totalEggs`. Additionally, I set the daily consumption `B[i]` as the initial value for the `needed` variable.

```javascript
        for (let i = 0; i < N; i++) {
            queue.push({ amount: A[i], day: i });
            totalEggs += A[i];

```

This is the core inventory management algorithm. `needed` represents the amount that must be used (unallocated consumption). I allocate the oldest stock first and continue until `needed` becomes zero (`while (needed > 0)`).

```javascript
            while (needed > 0) {
                if (queue[head].amount <= needed) {
                    needed -= queue[head].amount;

                    totalEggs -= needed;

```

In the `if` block, if the unallocated consumption `needed` is greater than or equal to the amount at the front of the queue, I subtract that amount from `needed` and `totalEggs`, and increment `head` to point to the next item in the queue. In the `else` block—where the current stock amount is greater than `needed`—I subtract `needed` from that stock and from `totalEggs`, then set `needed` to zero (since all consumption is now allocated). Once `needed` is zero, the loop terminates.

The second `while` loop handles expiration. Until the oldest stock's date is within the expiration limit—calculated as `(i - queue[head].day + 1) < D`—I subtract the expired stock from `totalEggs` and increment `head`. The condition `head < queue.length` is crucial to prevent errors when `head` reaches the end of the queue.

```javascript
            while (head < queue.length && (i - queue[head].day + 1) >= D) {

```
