数字の書かれたボールが$N$個が袋の中にあり、最大5個の指定されたボールを取り出したとき、袋の中のボールに書かれた数字の最小値を答える問題です。

本番では解けなかったのですが、このように問題を自分の言葉で書き換えてみると解けなかったのが不思議なくらいわかりやすい問題です。手順は以下の通り。

1. $N$個のボールについて、ボールの順番と書かれた数字をセットにして配列にする

2. 配列を、ボールに書かれた数字で`sort`し、さらに数字が小さい方から6つだけ切り取る

   ```javascript
       const arrayA = [];
       for (let i = 0; i < N; i++) {
           arrayA.push(nextNum());
       }
       const sortedA = [];
       for (let i = 0; i < N; i++) {
           sortedA.push({ val: arrayA[i], idx: i + 1 })
       }
       sortedA.sort((a, b) => a.val - b.val);
   	const candidates = sortedA.slice(0, 6);
   ```

3. 取り出すボールの順番を`removed`の`Set`の中に加えていく

4. 数字が小さい方から6つ切り出した順番のボールが`removed`の中にあるか判定していく。もし`removed`に含まれていないボールが見つかれば、そのボールに書かれた数字が最小の値となるので、`ans`の配列に`cand.val`を入れて、ループに戻る

   ```javascript
       const ans = [];
       for (let j = 0; j < Q; j++) {
           const K = nextNum();
           const removed = new Set();
           for (let k = 0; k < K; k++) {
               removed.add(nextNum());
           }
           for (const cand of candidates) {
               if (!removed.has(cand.idx)) {
                   ans.push(cand.val);
                   break;
               }
           }
       }
   ```

5. `\n`で接続して出力する

   ```javascript
       console.log(ans.join("\n"));
   ```

最大K個を取り出した残りのボールに書かれた最小値、なのでK+1個、特に今回はK=5なので6個だけ書かれた数字の小さいものを管理する。その6個から最大5個のボールを取り除いて、その中から書かれた数字が最小のものを見つければ良い。書いてみると簡単なのに本番でこれに気づいて解くことができないのが悔しいです。とはいえ、ABを解く速さも悪くないし、少しずつ実力が付いてきていることを信じて、まだ打席に立ち続けるつもりです。打席に立たなくなってしまったら永遠にできるようにならないですから。

This problem involves $N$ balls in a bag, each labeled with an index and a written number. Given $Q$ queries where up to 5 specific balls are removed, the task is to find the minimum value among the balls remaining in the bag.

Although I couldn't solve it during the contest, describing the problem in my own words makes the solution feel surprisingly clear. The steps are as follows:

1. Create an array of objects for the $N$ balls, storing both their written value and their original index.

2. Sort the array based on the written values and extract only the top 6 balls (since $K \leq 5$).

   ```javascript
       const arrayA = [];
       for (let i = 0; i < N; i++) {
           arrayA.push(nextNum());
       }
       const sortedA = [];
       for (let i = 0; i < N; i++) {
           sortedA.push({ val: arrayA[i], idx: i + 1 })
       }
       sortedA.sort((a, b) => a.val - b.val);
   	const candidates = sortedA.slice(0, 6);
   ```

3. For each query, add the indices of the balls to be removed into a `removed` Set.

4. Iterate through the top 6 candidates. The first ball whose index is not in the `removed` Set will have the minimum value. Push this value to the `ans` array.

   ```javascript
       const ans = [];
       for (let j = 0; j < Q; j++) {
           const K = nextNum();
           const removed = new Set();
           for (let k = 0; k < K; k++) {
               removed.add(nextNum());
           }
           for (const cand of candidates) {
               if (!removed.has(cand.idx)) {
                   ans.push(cand.val);
                   break;
               }
           }
       }
   ```

5. Join the answers with newlines and output the result.

   ```javascript
       console.log(ans.join("\n"));
   ```

Since we are looking for the minimum value after removing at most $K$ balls, we only need to keep track of the $K+1$ smallest values. In this case, since $K=5$, keeping the top 6 is sufficient.
