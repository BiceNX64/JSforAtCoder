オブジェクトを使って、登場する文字毎の回数を管理します。以下の書き方は覚えておきたいです。文字列に対して1文字ずつ、すでにオブジェクトのkeyに`char`が存在すれば元のvalueの値に`1`を加え、keyが存在しなければ`0+1`を代入します。

```javascript

        countMap[char] = (countMap[char] || 0) + 1;
    }
```

このオブジェクトのvalueの最大値を求める方法も知らなかったので勉強になりました。

```javascript

```

文字列を1文字ずつ区切って配列にし、出現回数が最大のもの以外をフィルターし、最後にまた一つの文字列にします。

```javascript
    const ans = S.split("")
        .filter(char => countMap[char] !== maxVal)
        .join("");
```

このあたりは他の問題でも使えそうなので、よく理解し、整理していつでも使えるようにしておきたいです。

## 🔠 [ABC447-C](https://atcoder.jp/contests/abc447/tasks/abc447_c)

```javascript
// ABC447
// https://atcoder.jp/contests/abc447/tasks/abc447_c
// 2026-03-02

"use strict";
const fs = require('fs');

function Main(input) {
    const args = input.trim().split(/\s+/);
    let cur = 0;
    const next = () => args[cur++];
    const nextNum = () => Number(next());
    const nextBigInt = () => BigInt(next());
    // const lines = input.replace(/\r/g, '').trim().split(/\n/);

    // 👇️ ロジックを記述 👇️

    let S = next();
    let T = next();

    let ptrS = 0;
    let ptrT = 0;
    let count = 0;

    while (ptrT < T.length) {
        if (S[ptrS] !== T[ptrT]) {
            if (S[ptrS] === "A") {
                ptrS++;
            } else if (T[ptrT] === "A") {
                ptrT++;
            } else {
                console.log(-1);
                return;
            }
            count++;
        } else {
            ptrS++;
            ptrT++;
        }
    }
    const remainS = S.slice(ptrS);
    for (let i = 0; i < remainS.length; i++) {
        if (remainS[i] === "A") {
            count++;
        } else {
            console.log(-1);
            return;
        }
    }
    console.log(count)

    // 👆️ ロジックを記述 👆️
}

Main(require("fs").readFileSync(process.platform === 'linux' ? "/dev/stdin" : process.argv[2], "utf8"));
```

2つの英小文字の文字列`S`と`T`について、`S`の任意の場所に`"A"`を追加する、または、削除することで`T`と一致させることができる場合はその最小回数を答え、できない場合は`-1`と回答する、という問題です。

最初、わたしは配列`S`に対して実際に`"A"`を追加/削除するという方法で解いた結果、TLEの判定となってしまいました。そこで前回([ABC446](./ABC446))のFIFOで在庫管理する問題でポインタの手法を学んだことを思い出し、`S`と`T`に対しそれぞれポインタ(`ptrS`と`ptrT`)を設定し、`"A"`を加えたり削除する代わりに、それぞれのポインタを動かしながら2つの文字列を比較することで処理の最小回数をカウントしてみました。

それぞれのポインタが当たっているSとTの文字(`S[ptrS]`と`T[ptrT]`)を比較し、それらが異なる場合、どちらかが`"A"`であればそのポインタを一つ進めて、どちらも`"A"`でない場合はそこで終了です(`-1`を出力)。また、`S[ptrS]`と`T[ptrT]`が一致する場合は、両方のポインタを進めて次の文字を比較します。

```javascript
    while (ptrT < T.length) {
        if (S[ptrS] !== T[ptrT]) {
            if (S[ptrS] === "A") {
                ptrS++;
            } else if (T[ptrT] === "A") {
                ptrT++;
            } else {
                console.log(-1);
                return;
            }
            count++;
        } else {
            ptrS++;
            ptrT++;
        }
    }
```

また、`ptrT`が`T`の最後を指し示したあと、文字列`S`に残っている文字をチェックする必要があることに注意します。ここでは、`slice`をつかって`ptrS`以降の部分を切り出して、その中に`"A"`が含まれていればカウントし、`"A"`以外の文字が含まれていたら`-1`を出力します。

```javascript
    const remainS = S.slice(ptrS);
    for (let i = 0; i < remainS.length; i++) {
        if (remainS[i] === "A") {
            count++;
        } else {
            console.log(-1);
            return;
        }
    }
```

The task is to remove all occurrences of the most frequent character(s) from a string *S* consisting of lowercase English letters, and output the remaining characters joined in their original order. My initial code was a bit messy, so I asked Gemini to help clean it up.

I used an object to manage the frequency of each character. The following syntax is very useful to remember: it iterates through each character of the string, and if the `char` already exists as a key in the object, it adds `1` to the current value; otherwise, it initializes it with `0+1`.

```javascript
    for (const char of S) {
        countMap[char] = (countMap[char] || 0) + 1;
    }
```

I also learned a new way to find the maximum value among the object's values:

```javascript
    const maxVal = Math.max(...Object.values(countMap));
```

Finally, I split the string into an array of characters, filter out those whose frequency matches the maximum, and join them back into a single string.

```javascript
    const ans = S.split("")
        .filter(char => countMap[char] !== maxVal)
        .join("");
```


Given two lowercase English strings `S` and `T`, the goal is to determine the minimum number of operations (adding or deleting the character `"A"` at any position in `S`) to make it identical to `T`. If it's impossible, output `-1`.

Initially, I tried to solve this by actually modifying the array `S` (adding/deleting), which resulted in a TLE (Time Limit Exceeded). Remembering the pointer technique I learned from the FIFO inventory problem in the previous contest ([ABC446](https://www.google.com/search?q=./ABC446)), I set up two pointers (`ptrS` and `ptrT`) for `S` and `T` respectively. Instead of modifying the string, I counted the operations by moving the pointers and comparing the characters.

I compared the characters pointed to by each pointer (`S[ptrS]` and `T[ptrT]`). If they are different, and if either one is an `"A"`, I advance that specific pointer and increment the operation count. If neither is an `"A"`, it's impossible, so I output `-1`. If `S[ptrS]` and `T[ptrT]` match, I advance both pointers to compare the next characters.

```javascript
    while (ptrT < T.length) {
        if (S[ptrS] !== T[ptrT]) {
            if (S[ptrS] === "A") {
                ptrS++;
            } else if (T[ptrT] === "A") {
                ptrT++;
            } else {
                console.log(-1);
                return;
            }
            count++;
        } else {
            ptrS++;
            ptrT++;
        }
    }
```

It's also important to check any remaining characters in `S` after `ptrT` reaches the end of `T`. I used `slice` to get the remaining part of `S` starting from `ptrS`. If all remaining characters are `"A"`, I add them to the count; if there's any other character, I output `-1`.

```javascript
    const remainS = S.slice(ptrS);
    for (let i = 0; i < remainS.length; i++) {
        if (remainS[i] === "A") {
            count++;
        } else {
            console.log(-1);
            return;
        }
    }
```
